# Domine a Tec 2.0

> Evolução do projeto científico Domine a Tec para uma aplicação web desenvolvida durante a formação em ADS.

## Sobre o projeto

O Domine a Tec 2.0 é uma plataforma educacional destinada a auxiliar estudantes na descoberta e utilização consciente e eficiente de recursos tecnológicos como ferramentas de apoio à aprendizagem.

O projeto tem origem no projeto científico "Conectados na Aprendizagem: Dominando a Tec.", desenvolvido em equipe a partir de uma pesquisa de campo realizada com estudantes.

A versão 2.0 representa a evolução do projeto original para uma aplicação web, sendo atualmente desenvolvida individualmente durante a formação em Análise e Desenvolvimento de Sistemas (ADS). A proposta é aplicar, na prática, conhecimentos adquiridos ao longo da formação, utilizando tecnologias como HTML, CSS, JavaScript, Python, Flask, PostgreSQL e Git.

## Problema

A pesquisa identificou que muitos estudantes reconhecem que a tecnologia pode ser utilizada como apoio aos estudos, mas não sabem como utilizá-la de maneira eficiente.

Também foi observado o uso de Inteligência Artificial pelos estudantes sem o conhecimento necessário para utilizá-la adequadamente no processo de aprendizagem.

## Objetivo

Desenvolver uma plataforma que auxilie estudantes a conhecer e utilizar recursos tecnológicos de forma mais eficiente no processo de aprendizagem, oferecendo informações, orientações e ferramentas que contribuam para a organização e melhoria dos estudos.

## Origem

O projeto atual é uma evolução do protótipo original desenvolvido em Kodular e apresentado em feiras científicas. A versão 2.0 busca transformar a proposta original em uma aplicação web mais completa, utilizando conceitos de desenvolvimento de software, programação, banco de dados e arquitetura de sistemas aprendidos durante a formação em ADS.
